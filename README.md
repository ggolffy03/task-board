# 📋 Task Board

บอร์ดจัดการงานส่วนตัว — อัปเดตผ่าน Discord (Hermes)

- **วางแผน** → งานที่วางแผนไว้
- **กำลังทำ** → งานที่ทำอยู่
- **รอทดสอบ** → เสร็จแล้ว รอทดสอบ/รอผล
- **เสร็จ** → จบงาน

ข้อมูลทั้งหมดเก็บใน `tasks.json` — แก้ผ่าน Discord แล้วบอร์ดจะอัปเดตอัตโนมัติ
